Privacy Policy

Last updated: September 18, 2026

This Privacy Policy explains how the personal-use application GMO Trading Backup handles information when using Google OAuth and Google Drive.

1. Purpose of access

Google Drive access is used solely to store, retrieve, verify, and manage encrypted backup files created by the account owner's system.

2. Data handled

The application may process encrypted backup files, file metadata, and OAuth authorization credentials needed to connect to Google Drive.

3. Storage and security

Backup content is encrypted before upload. OAuth tokens are stored on the account owner's private server and are not stored by this website.

4. Data sharing

The application does not sell personal information and does not provide Google user data to advertisers or unrelated third parties.

5. Retention and deletion

Backup files remain in Google Drive according to the configured retention policy. The account owner may delete backup files and revoke Google account access at any time.

6. Public website

This website does not collect passwords, API keys, trading credentials, Google Drive files, or payment information.
